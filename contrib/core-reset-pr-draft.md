## Proposed change
<!--
  Describe the big picture of your changes here to communicate to the
  maintainers why we should accept this pull request. If it fixes a bug
  or resolves a feature request, be sure to link to that issue in the
  additional information section.
-->

Pressing Evohome's system reset button can leave a domestic-hot-water override
active on a controller that supports native AutoWithReset. Explicitly reset DHW
after resetting the controller, and request a coordinator refresh in `finally`
so state is refreshed even if the second command fails.

The change keeps the existing button and services. It adds regression cases for
controllers with and without DHW and for failure during the DHW reset, and
updates the existing service-path test to require the DHW call.
